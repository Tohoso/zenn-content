Even Realities G2（576×288 / 眼、4-bit グレースケールのスマートグラス）向けに、リモート tmux セッションをレンズに映して、こめかみダブルタップで音声入力を送り返す OSS を書いた。

- リポジトリ: https://github.com/Tohoso/tmux-on-g2
- ライセンス: MIT
- 公開: 2026-04-19（Beta 配信）

ハードウェア依存の絵ネタに見えるけど、実装の肝は

- Even Hub SDK 0.0.7 の class-first 流儀（docs と signature が違う）
- Whisper ホステッド API の幻覚問題を client 側で止血する
- Claude Code 2.1.x の bracketed-paste 検出を `tmux send-keys` で突破する

あたりにあって、SDK 以外は G2 を持ってない人にも再利用できると思う。以下、踏んだ罠と解決を残す。

## 全体構成

```
tmux が走ってるホスト (Linux)
  └ tmux-g2-bridge (FastAPI + systemd, :18820)
        ├ WS  /tmux    tmux capture-pane 500 ms ごとに diff push
        ├ POST /asr    Whisper 互換 ASR プロキシ
        └ GET /healthz

スマホ (Even Realities app)
  └ WebView
        └ Vite + TS + @evenrealities/even_hub_sdk@0.0.7
              ↕ Bluetooth 5.2
        ┌ Even G2 (レンズ) ┐
        │ 576×288 / 4-bit │
        │ LVGL 固定フォント │
        └──────────────────┘
```

G2 の制約メモ（全部 `docs/SDK-NOTES.md` に残してある）:

- 576×288 / 眼、4-bit グレースケール（16 階調の緑）
- LVGL firmware 固定フォント。**フォントサイズ / weight / color API なし**
- テキストコンテナ: `createStartUpPageContainer` で 1000 字、`textContainerUpgrade` で 2000 字。全画面で ~400–500 字
- 1 ページに最大 12 コンテナ（text 8 + image 4）、**`isEventCapture: 1` はちょうど 1 個**
- ジェスチャ: CLICK / DOUBLE_CLICK / SWIPE_TOP / SWIPE_BOTTOM / FG_ENTER / FG_EXIT / ABNORMAL_EXIT。長押しは Even AI 専用で来ない
- 音声: 16 kHz 16-bit LE mono PCM、`audioEvent.audioPcm` （次項）

## 罠1: SDK 0.0.7 は class-first、公式チュートリアルの signature は嘘

`@evenrealities/even_hub_sdk@0.0.7` の [getting-started チュートリアル](https://hub.evenrealities.com/docs/getting-started/first-app) には：

```ts
// ❌ docs にあるけど SDK 0.0.7 には存在しない signature
await bridge.createStartUpPageContainer(1, [container]);
```

と書かれている。これで叩くと `return=1`（invalid）で黙って死ぬ。ログも出ない。

型定義を読むと、実際は単引数クラス：

```ts
import {
  waitForEvenAppBridge,
  CreateStartUpPageContainer,
  TextContainerProperty,
  TextContainerUpgrade,
} from "@evenrealities/even_hub_sdk";

const bridge = await waitForEvenAppBridge();

const text = new TextContainerProperty({
  xPosition: 0, yPosition: 0, width: 576, height: 288,
  containerID: 1, containerName: "tmux",
  content: "waiting for tmux stream...", isEventCapture: 1,
  borderWidth: 0, borderColor: 5, paddingLength: 4,
});

await bridge.createStartUpPageContainer(
  new CreateStartUpPageContainer({ containerTotalNum: 1, textObject: [text] })
);
```

SDK のブリッジメソッドはすべてクラスインスタンスを取る。プレーンオブジェクトを投げると `invalid` か `false` で静かに拒否される。

さらに返り値も API によって方言がある。

| API | 返り値 |
|---|---|
| `createStartUpPageContainer` | `Promise<number>` (0=OK, 1=invalid, 2=oversize, 3=memory) |
| `textContainerUpgrade` / `rebuildPageContainer` / `audioControl` | `Promise<boolean>` |
| `updateImageRawData` | `Promise<ImageRawDataUpdateResult>` (独自 enum) |

慣れないうちは `if (res !== 0)` と `if (!ok)` と `if (res.code !== ...)` を混同して事故る。型を信じて素直に書く。

## 罠2: audio フィールドは `audioPcm`、`pcm` じゃない

`onEvenHubEvent` 経由で来る音声イベント：

```ts
event.audioEvent?.audioPcm  // ← これ
// event.audioEvent?.pcm    // ← 最初これで書いて 1 時間溶かした
```

フィールド名が `audioPcm` で、`pcm` にしても型エラーは出ず、実行時も例外は出ず、ただ silently にデータが空になる。ホストによっては `Uint8Array` / `number[]` / base64 文字列のどれかで来るので、自前で defensive に正規化する。

```ts
function normalizePcm(raw: unknown): Int16Array | null {
  // Uint8Array → Int16Array (little-endian)
  if (raw instanceof Uint8Array) {
    return new Int16Array(raw.buffer, raw.byteOffset, raw.byteLength / 2);
  }
  if (Array.isArray(raw)) {
    return Int16Array.from(raw);
  }
  if (typeof raw === "string") {
    const bin = atob(raw);
    const buf = new Uint8Array(bin.length);
    for (let i = 0; i < bin.length; i++) buf[i] = bin.charCodeAt(i);
    return new Int16Array(buf.buffer);
  }
  return null;
}
```

16 kHz / 100 ms / 16-bit mono だと 1 フレーム = 3200 bytes = 1600 samples。

## 罠3: Whisper が沈黙で「ご視聴ありがとうございました」を吐く

Whisper あるあるだが、無音や環境ノイズに対して YouTube の定型句を生成する。日本語だと：

- 「ご視聴ありがとうございました」
- 「チャンネル登録よろしくお願いします」
- 単なる句読点だけの行

Groq のホステッド Whisper (`whisper-large-v3`) は `no_speech_threshold` / `logprob_threshold` を露出してないので、サーバ側で逃げる口がない。クライアント側で 2 段ゲート。

**VAD (RMS ベース):**

```ts
function computeRms(chunks: Int16Array[]): number {
  let sumSq = 0, n = 0;
  for (const c of chunks) {
    for (let i = 0; i < c.length; i++) {
      const s = c[i] / 32768;
      sumSq += s * s;
    }
    n += c.length;
  }
  return n === 0 ? 0 : Math.sqrt(sumSq / n);
}

async finish(): Promise<string> {
  const rms = computeRms(this.chunks);
  const samples = this.chunks.reduce((n, c) => n + c.length, 0);
  const durationSec = samples / 16000;
  if (rms < 0.01 || durationSec < 0.4) return "";   // send しない
  // ... WAV 化して POST ...
}
```

閾値 `rms < 0.01` はカフェ程度の環境音でも通るくらいの緩さ。`0.4 s` 未満は誤ダブルタップ対策。

**幻覚 blocklist:**

```ts
const HALLUCINATION_PATTERNS = [
  /^\s*ご視聴(?:ありがとう|いただき).*$/,
  /^\s*ありがとうございました[。!！\s]*$/,
  /^\s*Thank(?:s| you)( for watching)?[.!\s]*$/i,
  /^\s*チャンネル登録.*$/,
  /^\s*[。、,.\s]*$/,
];

function filterHallucinations(text: string): string {
  const trimmed = text.trim();
  for (const re of HALLUCINATION_PATTERNS) {
    if (re.test(trimmed)) return "";
  }
  return trimmed;
}
```

VAD を抜けてきてもなお幻覚が出ることがある（咳払い、机を叩く音など）ので、最後にもう一段漉す。

ちなみに Groq の `whisper-large-v3` と `whisper-large-v3-turbo` だと、日本語精度は明らかに無印のほうが良い。`-turbo` は英語向けに軽量化されていて、日本語の語尾や助詞を落としやすい。

## 罠4: `tmux send-keys <text> Enter` の Enter を Claude Code が食う

ASR の結果を tmux pane に流し込むとき、素朴にやるとこう書きたくなる：

```bash
tmux send-keys -t ayu-cc "hello" Enter
```

これが Claude Code 2.1.x では壊れる。クライアントが「短時間に複数文字が届いた → これは paste だな」と判断して、bracketed-paste モードで受け取ってしまう。結果、テキストは入力欄に入るけど、trailing Enter は paste の内部として握りつぶされ、送信されない。

回避は分割＋ sleep：

```python
async def _send_keys(target: str, text: str) -> None:
    base = ["sudo", "-n", "-u", TMUX_USER, "tmux", "send-keys", "-t", target]
    # Two-shot to defeat CC 2.1.x paste detection.
    p1 = await asyncio.create_subprocess_exec(*base, text)
    await p1.wait()
    await asyncio.sleep(SEND_KEYS_DELAY_MS / 1000.0)   # 500 ms
    p2 = await asyncio.create_subprocess_exec(*base, "Enter")
    await p2.wait()
```

bracketed-paste のタイマー（クライアント実装依存、概ね 50–200 ms）を跨ぐだけでいい。マージン込みで 500 ms に置いてる。短くしたいなら 300 ms から詰めていくと実環境で壊れ始めるラインが見える。

## 罠5: Claude Code chrome trim

G2 は全画面で 400–500 字しか乗らない。tmux pane をそのまま流すと、Claude Code の画面下に固定されてる入力ボックス・タスクリスト・ステータスバーが常に見えてしまい、実体の出力が追いやられる。

入力ボックスのパターンは幸い distinctive で、`─` 横罫線 → `❯` プロンプト行 → `─` 横罫線の 3 行 sandwich。これを anchor にして、その上にぶら下がってるタスク行（`◼` / `◻` / `✔` / `⎿` / `…` / `N tasks (…)`）を削る：

```ts
function trimCcChrome(lines: string[]): string[] {
  let anchor = -1;
  for (let i = 0; i <= lines.length - 3; i++) {
    if (
      /─{10,}/.test(lines[i]) &&
      /^\s*❯/.test(lines[i + 1]) &&
      /─{10,}/.test(lines[i + 2])
    ) {
      anchor = i; // live pane の歴史的罫線を拾わないよう最後の match を採用
    }
  }
  if (anchor < 0) return lines;  // プレーンシェル等はそのまま

  let cut = anchor;
  while (cut > 0) {
    const prev = lines[cut - 1].trim();
    if (prev === "") { cut--; continue; }
    if (/^[◼◻✔⎿]/.test(prev)) { cut--; continue; }
    if (/^…/.test(prev)) { cut--; continue; }
    if (/^\d+ tasks? \(/.test(prev)) { cut--; continue; }
    break;
  }
  while (cut > 0 && lines[cut - 1].trim() === "") cut--;
  return lines.slice(0, cut);
}
```

他 TUI 対応は PR 募集中。heuristic を足していけるよう、chrome detection はこの 1 関数に閉じ込めた。

## 罠6: Even Hub ポータルの Private は「draft 扱い」

最後は運用罠。Even Hub 開発者ポータルでビルドをアップすると、初期ステータスは **Private**。この状態で自分自身をテスターに追加し、招待メールのリンクを踏んでも：

> テスト版の有効期限が切れました

と出てインストールできない。公式 docs にこの挙動の記載がない。ポータルの UI でビルドのステータスを **Private → Beta** に遷移させて、初めてテスターが受け取れる状態になる。招待リンクは短時間で失効するので、ステータス変更 → すぐ踏む、の順で。

ここだけで 2 時間溶かした。同じ時間を使う人が減るよう、`docs/SDK-NOTES.md` と TROUBLESHOOTING に両方残してある。

## textContainerUpgrade vs rebuildPageContainer

細かいけど性能にクリティカルなので書いておく。G2 にテキストを再描画する API は 2 つある。

- `textContainerUpgrade` — 既存コンテナの content を in-place 更新。`Promise<boolean>`、BT トラフィック最小
- `rebuildPageContainer` — ページ定義を丸ごと差し替え。重い

tmux の末尾を 500 ms ごとに tail 更新する用途では **`textContainerUpgrade` 一択**。firmware がスクロール位置を保持したまま文字だけ差し替えてくれる。`rebuildPageContainer` はテキスト → 画像表示のモード切り替えみたいな構造変更だけに使う。

私は最初これを間違えて、毎フレーム `rebuildPageContainer` を叩いて「なんか描画がガクつくな……」と 30 分悩んだ。

## ブリッジ側のセキュリティ最小限

ブリッジは root で動かして、tmux 操作だけ `sudo -n -u <TMUX_USER>` で unprivileged ユーザに落とす。bearer token は `secrets.compare_digest` でタイミング攻撃耐性の比較：

```python
def _const_eq(a: str, b: str) -> bool:
    return secrets.compare_digest(a.encode(), b.encode())

def _check_token(request, token_q):
    if not BRIDGE_TOKEN:
        raise HTTPException(503, "server not configured")
    if token_q and _const_eq(token_q, BRIDGE_TOKEN):
        return
    auth = request.headers.get("authorization", "") if request else ""
    if auth.startswith("Bearer ") and _const_eq(auth[7:], BRIDGE_TOKEN):
        return
    raise HTTPException(401, "unauthorized")
```

WS キャプチャ対象の tmux session は `ALLOWED_TARGETS` でホワイトリスト。未登録の session 名を投げると 400 で落とす。`/asr` は API key を載せて Groq/OpenAI/セルフホストに横流しするだけ（公開するなら rate limit を必ず足す、今は入ってない）。

ネットワークは Tailscale が一番楽。同一 LAN か cloudflared でもいい。外に晒すなら `tailscale serve` か reverse proxy 経由で TLS termination して、`127.0.0.1` にブリッジを bind する。

## まとめ

- Even Hub SDK 0.0.7 は class-first。docs の signature を鵜呑みにしない
- audio フィールドは `audioPcm`
- Whisper 幻覚は client RMS-VAD + blocklist で挟み撃ち
- CC 2.1.x の `send-keys` は text と Enter を 2 発に分離
- Claude Code chrome は入力ボックスの `─ ❯ ─` 3 行 sandwich を anchor に trim
- Private → Beta の status 遷移は必須

この手の「docs に書かれてない罠」は、踏んだ人がメモを残さないと次の人も同じ時間を溶かす。Even Hub まわりは特に、SDK 0.0.x の時期にどれだけ知見が溜まるかで 0.1.x 以降のエコシステム速度が変わる気がする。
